# 📚 Repositorio de Scripts

> **Repositorio exclusivo para el desarrollo y almacenamiento de scripts relacionados con las actividades y tareas académicas.**

## 🎯 Propósito

Este repositorio está destinado **exclusivamente a subir scripts aptos y necesarios para cumplir con los requerimientos de las tareas y actividades asignadas**.

Los archivos aquí almacenados tienen como objetivo facilitar la organización, desarrollo y entrega de las prácticas y ejercicios correspondientes.

## 📂 Contenido

En este repositorio se podrán encontrar:

* 📝 Scripts desarrollados por rol.
* 💻 RECUPERACION.
* 🔧 SEGURIDAD.
* 📖 MONITOREO.
* 🕌 Scritps iniciales para la creacion de la DB

## ⚠️ Nota

El contenido de este repositorio está orientado **únicamente al cumplimiento de las actividades académicas**. Cada script debe mantenerse relacionado con los objetivos y requerimientos de las tareas correspondientes.
